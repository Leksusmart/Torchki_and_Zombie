# Torchki and Zombie

2D-игра на **Qt / QML + C++**, в которой игрок защищает город от зомби-апокалипсиса.

Цель — полностью очистить карту от зомби и инфицированных, используя вакцины, десант солдат и точки эвакуации.

## Основные механики

- Процедурная генерация города из PNG-маски (дороги, здания, эвак-точки)
- Жители с дневным/ночным расписанием (работа / дом)
- Распространение инфекции → зомби
- Солдаты, огонь, разрушение зданий
- Инструменты: вакцинирующая капсула, отряд десанта, точка эвакуации
- Бюджет и налоги с работающих жителей
- День / ночь цикл

## Технологии

- **Qt 6** (QML + C++)
- Scene Graph для рендера карты и юнитов
- CMake

## Структура проекта

├── CMakeLists.txt

## Сборка

```bash
cmake -B build -S .
cmake --build build
```

Требуется Qt 6 с модулями Quick, Qml.
